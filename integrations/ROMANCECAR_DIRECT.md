# ロマンスカー到着3分前、自作Galaxy Alarmだけで自動登録（MacroDroid不要）

構成：Gmail → 自分のGoogle Apps Script Webアプリ → Galaxy Alarm (WorkManagerで15分ごとに確認) → 到着3分前に振動アラーム

## 初期設定（初回だけ）

1. Galaxy Alarmを本機能対応APKへ更新（既存アラームは維持）
2. Googleの [Apps Script](https://script.google.com/) で新規プロジェクトを作成
3. [romancecar_direct.gs](romancecar_direct.gs) の全文を貼り付ける
4. Galaxy Alarmの「設定 → ロマンスカー到着アラーム → トークンをコピー」
5. Apps Script の「プロジェクトの設定 → スクリプトプロパティ」で以下を保存する
   - 名前：`ROMANCECAR_SYNC_TOKEN`
   - 値：コピーしたGalaxy Alarmのトークン
6. Apps Scriptの「デプロイ → 新しいデプロイ → ウェブアプリ」で
   - 次のユーザーとして実行：「自分」
   - アクセスできるユーザー：「全員」
   - アクセス許可画面でGmailへのアクセスを許可
7. 生成された `https://script.google.com/macros/s/.../exec` をGalaxy Alarmの設定画面に貼り付けて「保存・同期」
8. 「同期状態」で最終同期とエラーを確認

「全員」で公開したURLでも、32文字以上のランダムなトークンがPOST本文に一致しないと予約データを返さない方式。ただし公開WebアプリなのでURLとトークンを第三者に渡さないこと。Apps ScriptはGmailを自分の権限で検索する。アラームアプリが取得するのは到着日時、駅、確認番号だけでメール本文は返さない

## 動作仕様

- 対象：送信者 `no-reply@maasjapan.net` 、件名ロマンスカー、購入完了・変更完了
- 自作Alarmが15分間隔でGoogle Apps Scriptをチェック。アプリを起動した際や「保存・同期」でも直ちに同期を要求
- 到着予定が12時間以内になったら、「ロマンスカー（自動）」グループに、到着3分前の「音なし・振動あり」アラームをONで作成
- 同じ予約確認番号の変更メールでは既存アラームの到着駅／時刻を更新。次の予約日時が12時間以上先なら古いアラームを一旦OFFにする
- 登録済みの単発アラームはAndroid AlarmManagerの `setAlarmClock()` で正確な時刻に鳴るようスケジュール。メール確認自体はWorkManagerのため遅延し得る
- 途中で予約キャンセル・払い戻しをしてもアラーム自動解除は未対応。手動でOFFにすること
- 端末オフライン、Android省電力制御、アプリの強制停止、Gmail同期遅延、Apps Script実行エラー時は自動登録が失敗し得る
- Gmailメールを受信した直後の自動反映は保証しない。出発直前に購入した場合は「保存・同期」を押すか手動で設定

## 動作確認

1. Galaxy Alarmの設定でApps ScriptのURLを保存後、同期状態が「同期成功」になることを確認
2. 到着まで12時間以内の未来の予約がある場合、「ロマンスカー（自動）」グループに登録されることを確認
3. 音なし・振動あり・繰り返しなし・到着の3分前になっていることを確認
4. 予約変更後、再同期で同じ予約のアラームが更新されることを確認
5. アプリ更新／再起動のあとも登録済みアラームが保持されることを確認
